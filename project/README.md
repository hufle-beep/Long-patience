# Project folder: Selene: Tidelocked

Everything needed to carry on work on this game without losing context. A new chat (or a new person) should read these in order:

1. **[working-agreement.md](working-agreement.md)**: the HARD RULE and every standing rule. Read first, always follow.
2. **[handover.md](handover.md)**: how the game is built, how saves/builds/tests work, where things are, and the current state.
3. **[roadmap.md](roadmap.md)**: what is next, what is waiting on the owner, and what is parked.
4. **[playtest-notes.md](playtest-notes.md)**: the section-by-section retune: values, bot results, playtest runs, frozen sections.
5. **[design.md](design.md)**: world, lore and the Act II design; Act III parked items.
6. **[changelog.md](changelog.md)**: every build, newest first.
7. **[restore-points.md](restore-points.md)**: fallback branches, the last 5 restore points and how to roll back.
8. **[research.md](research.md)**: ideas from other open-source incremental games (licences, what's built, what's open).
9. **[tools/](tools/)**: test bots, the regression tests, the sanity check, screenshot and snapshot scripts (see tools/README.md).

The same documents (except tools and the changelog) are mirrored in the claude.ai project "Incremental scifi game" under `claude/`. **This folder is the master copy**; every push updates it in the same commit.
